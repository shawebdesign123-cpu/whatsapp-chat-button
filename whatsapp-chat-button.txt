Step 1: Create Your Custom WhatsApp Link
WhatsApp provides a special format called Click to Chat that opens a direct chat window with your business phone number.
1.	Format your phone number: Use your country code followed by your phone number without any +, spaces, dashes, or leading zeros.
o	Example for Sri Lanka (+94): If your number is 071 234 5678, write it as 94712345678.
2.	Build your URL:
o	Basic link:
[https://wa.me/94712345678](https://wa.me/94712345678)
o	Link with a pre-filled message (Recommended):
[https://wa.me/94712345678?text=Hello%20Priyadi%20Nature%20Food,%20I%20have%20an%20inquiry%20about%20your%20products](https://wa.me/94712345678?text=Hello%20Priyadi%20Nature%20Food,%20I%20have%20an%20inquiry%20about%20your%20products).
Verification: Copy and paste your constructed URL into any browser. It should open WhatsApp and prompt you to send the specified message.

Alternative: Using WordPress Plugins (If using WordPress/WooCommerce)
If your site runs on WordPress or WooCommerce, you can install a plugin instead of manually editing code:
1.	Log in to your WordPress Dashboard.
2.	Go to Plugins > Add New.
3.	Search for "Joinchat" or "Click to Chat".
4.	Click Install Now and then Activate.
5.	Go to the plugin settings, enter your phone number with the country code (e.g., 94712345678), set your custom greeting message, and click Save Changes.
